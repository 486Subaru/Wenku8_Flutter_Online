# 日轻（Riqing）

> 非官方开源派生项目。基于 **MewX** 的 Wenku8 项目继续维护与扩展。

**当前 Android 版本：0.5.5+2286（ARM64）**

## 项目说明

「日轻」保留 Wenku8 0.5.5 的阅读界面、本地书库与阅读体验，并恢复、整理已经失效或移除的联网能力。当前分支重点包括：

- 在线主页、搜索、详情、目录与章节正文；
- 多书源管理与自定义书源；
- 登录网站与主页书源分离；
- 不同书源 Cookie / 登录状态隔离；
- Wenku8 新旧域名兼容；
- 轻之文库、轻之国度等站点的现行接口适配；
- 单书源异常隔离、缓存和网络稳定性优化。

第三方网站随时可能修改域名、接口、登录方式或页面结构，因此不保证所有书源永久可用。

## 更新通道

从 **v2286** 起，应用内更新只检查本项目自己的 GitHub Release：

`486Subaru/Wenku8_Flutter_Online`

不再检查原版 `mikufoxxx/Wenku8_Flutter`，也不再使用原版更新镜像，因此不会再把原版更新误提示成「日轻」更新。

GitHub Release 的 Android ARM64 安装包应命名为：

`riqing-0.5.5-arm64-v8a.apk`

Release 标签应包含版本与 build，例如：`v0.5.5+2286`。

> 当前仓库若仍为 Private，匿名应用内更新检查无法读取 Release；把仓库及对应 Release 公开后才会正常工作。

## 安装

Android 使用独立包名：

`org.mewx.wenku8_flutter.online.fix`

因此可以与原版并存，不需要卸载原版。
